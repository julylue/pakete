# Pakete

Pickliste für die Vinted-Pakete: Packen, Wegbringen, Abgegeben. Läuft auf GitHub Pages.

Daten: private Google-Tabelle "Pakete Pickliste" (Ordner Vinted & Co.), angebunden über das Google-Skript "Pakete Schnittstelle" (Code.gs, ohne Schlüssel).
Zugang nur über den persönlichen Link mit Schlüssel (?k=...).

Abgabestellen: GLS = Türkischer Supermarkt, DHL = Foto Kasse, Hermes = Mr. Kiosk, DPD = NKD.

Wichtig: Dieses Repo ist öffentlich. Nie Schlüssel, private Links oder Namen hier ablegen.
